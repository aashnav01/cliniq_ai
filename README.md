# ⚕️ ClinIQ

**AI-Powered Clinical Workflow Assistant**

![ClinIQ Application Demo](demo.webp)

ClinIQ is a modern, AI-driven application designed specifically for doctors and healthcare professionals. Built to run alongside a busy hospital shift, ClinIQ reduces documentation burden, mitigates cognitive fatigue, and acts as an intelligent safety net. 

Instead of treating AI like a generic chatbot, ClinIQ integrates large language models directly into structured, daily clinical workflows.

---

## ✨ Key Features & How They Help Doctors

### 1. 📝 Consultation Note Processor (SOAP Module)
Doctors often jot down messy, shorthand notes during patient encounters. 
* **What it does:** Takes raw, unstructured text (or 5-10 word "rapid" bursts) and automatically formats it into a professional, structured SOAP (Subjective, Objective, Assessment, Plan) note.
* **Clinical Benefit:** Saves hours of typing. You can focus on the patient, dump your thoughts quickly, and let the AI handle the formatting.
* **Multilingual Rapid Mode:** Supports typing shorthand in regional languages (Hindi, Tamil, Telugu, etc.) and auto-translates it into an English SOAP note while generating a patient-friendly summary in the original language.
* **Smart Extractions:** Automatically detects medications and suggests generic (Jan Aushadhi) alternatives, and allows you to generate a formal specialist Referral Letter in one click.

### 2. 🧠 Differential Diagnosis Assistant (DDx Module)
* **What it does:** Takes patient demographics, vitals, and presenting symptoms to generate a ranked list of differential diagnoses. 
* **Clinical Benefit:** Acts as a cognitive safety net. It assigns confidence scores, suggests tests to confirm or rule out conditions, and explicitly highlights **Critical Exclusions** (life-threatening conditions you *must* rule out).
* **Clinician Pushback:** Doctors can challenge the AI (e.g., *"This is unlikely because..."*) forcing the model to recalculate based on the doctor's clinical reasoning.

### 3. 🏥 Shift Handover Briefing
* **What it does:** Parses chaotic, stream-of-consciousness handover notes (e.g., *"Bed 4 Mr Patel chest pain... Bed 5 DKA sugars dropping..."*) and organizes them into structured Patient Cards.
* **Clinical Benefit:** Ensures nothing is missed during shift changes. It automatically sorts patients by urgency (Critical, High, Stable), highlights events to watch out for, and extracts actionable items into a clickable **Task Checklist**.

### 4. 🛡️ Built-in Clinical Guardrails
* **Drug Interaction Checker:** Automatically scans the treatment plan for dangerous medication combinations and flags them.
* **Red Flag Alerts:** Identifies critical symptoms in your notes and raises prominent alerts before you finalize the patient's chart.
* **NEWS2 Calculator:** A built-in calculator for the National Early Warning Score to quickly assess illness severity.

### 5. 🎙️ Native Multilingual Voice Dictation
* **What it does:** Allows doctors to dictate notes directly into the application using their browser's native speech recognition.
* **Clinical Benefit:** Supports hands-free data entry in multiple regional languages (English, Hindi, Tamil, Telugu, Bengali, Marathi), significantly speeding up charting.

### 6. 📄 Professional PDF Exports
* **What it does:** Automatically strips away the dark theme and UI elements to generate a clean, print-ready clinical document.
* **Clinical Benefit:** Ensures that notes generated by the AI look like formal EHR documents, ready to be printed or saved to a patient's physical file.

## 🛠️ Tech Stack

* **Frontend:** React + Vite (Vanilla CSS with a modern Glassmorphic design system)
* **Backend:** Python + FastAPI
* **Database:** SQLite (with SQLAlchemy) 
* **AI Engine:** Groq API (High-speed LLaMA/Mixtral inference)

## 🚀 How to Run Locally (Windows)

### Prerequisites
1. **Node.js** (v18+)
2. **Python** (v3.10+)
3. A **Groq API Key**

### 1. Environment Setup
Create a `.env` file in the `backend/` directory and add your Groq API key:
```env
GROQ_API_KEY=your_api_key_here
```

### 2. Quick Start (Using Batch Scripts)
We've included handy Windows batch scripts to make starting the project a one-click process.

**To run the app:**
Double-click `start-dev.bat` in the root folder, or run it via terminal:
```cmd
.\start-dev.bat
```
*This will automatically launch the FastAPI backend (port 8000) and the Vite frontend (port 5173) in separate command prompt windows.*

### 3. Manual Startup
If you prefer to start the services manually:

**Start the Backend:**
```cmd
cd backend
venv\Scripts\activate
python main.py
```

**Start the Frontend:**
```cmd
cd frontend
npm run dev
```
